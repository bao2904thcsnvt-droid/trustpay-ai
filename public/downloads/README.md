# Tệp cài đặt Android (APK)

Đặt tệp APK đóng gói bằng [PWABuilder](https://www.pwabuilder.com/) vào đây với tên **`trustpay-ai.apk`**.

- Có tệp → nút **"Tải tệp Android (.APK)"** trên giao diện tải thẳng tệp về máy.
- Chưa có tệp → nút đó mở hướng dẫn cài ứng dụng 1 chạm qua Chrome (*Cài đặt ứng dụng*).

Đóng gói: mở PWABuilder → nhập URL bản triển khai (vd. Vercel) → *Package for stores* → **Android** →
tải gói về, đổi tên tệp `.apk` thành `trustpay-ai.apk` rồi đặt vào thư mục này.
